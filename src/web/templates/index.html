Real-time noise suppression

A U-Net predicts a 0–1 mask over the noisy spectrogram and multiplies it in, pulling the speaker out of background noise. Trained on VoiceBank + DEMAND.

Model on the test set

Dataset

VoiceBank + DEMAND pairs every clean sentence with the same sentence mixed with real-world noise (traffic, cafe, station, kitchen, ...) at four signal-to-noise ratios. The model never sees the test speakers.

Model

The network sees the magnitude spectrogram as a grayscale image, predicts a mask the same size, and multiplies that mask into the noisy spectrogram. The original noisy phase is reused to synthesize the waveform.
